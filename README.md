## 🧠 How I learn

```
sync → next → learn + code → stuck? → review → done → sync
```

- 👨‍🏫 **AI mentor (Claude Code)** teaches every lesson, then gives **hints, not answers**. I write all my own code.
- 🎥 **3–4 YouTube videos per lesson**, matched to the exact topic
- 🧪 One practice exercise per lesson, plus one portfolio project per module
- 🔁 Spaced revision, 🐞 weekly bug hunts, 🎤 mock interviews
- ✅ A module only counts when the project is **on GitHub, live, and I can explain every line**
