# 📋 My Course Commands: Cheat Sheet

## A normal study day (30–60 min, weekday mornings)
```
sync  →  next  →  learn + code  →  (stuck if blocked 15+ min)  →  done  →  sync
```

## Where to type what
- 📌 **Coding – Main** = the HUB: `sync`, `next module`, `progress`, `commands`, `quiz`, `revise`, `debug`, `interview`, `schedule`, `behind`, `setup this pc`
- 📘 **Module N** (e.g. Module 0 – Basics) = LESSONS: `next`, `stuck`, `explain`, `review`, `glossary`, `done`

## Every day
| Command | Where | What it does |
|---|---|---|
| `sync` | Main | Upload my work to GitHub + download the latest from my other PCs. Start AND end every session with it. |
| `next` | Module | Start the next lesson (test-out quiz first: get 3/3 right to skip it) |
| `stuck` | Module | Claude reads my code and the error and gives hints, not answers |
| `done` | Module | End the session: summary, progress saved, tomorrow's plan |
| `next module` | Main | Open the next module's session (only when the current module is fully done) |

## Checking my work (Module session)
| Command | What it does |
|---|---|
| `review` | Check my finished project against its checklist, then the "can I explain it?" questions |
| `explain` | Explain the last topic again, more simply |

## Practice (each opens its own session)
| Command | Opens | What it does | How often |
|---|---|---|---|
| `quiz` | ❓ Quiz | 5 questions on my weak spots | Any time |
| `revise` | 🔁 Revise | Review OLD topics before I forget them | Every 3 days |
| `debug` | 🐞 Debug | Fix a small broken program, then type `fixed` | About once a week |
| `glossary` / `glossary <word>` | (stays in Main) | My coding word list in simple English | Any time |

## Planning and tracking
| Command | What it does |
|---|---|
| `progress` | Open the 📊 Progress session (big-picture dashboard) |
| `update progress` | Save my progress now |
| `schedule` | This week's timetable |
| `make calendar file` | This week's timetable as a Google Calendar file |
| `behind` | Honest check: should I switch to the backup plan? |

## Other sessions and devices
| Command | What it does |
|---|---|
| `commands` | Open the 📋 Commands session (this list + "what does X do?") |
| `sidechat` | Open a 💬 Side chat for any question without disturbing the lesson |
| `interview` | Open the 🎤 Mock interview session |
| `setup this pc` | Install everything on my other laptop or PC |
| `help` | Show this list |

## My sessions (sidebar group 💻 Coding)
| Session | Use it for |
|---|---|
| 📌 Coding – Main | The hub: sync, setup, opening other sessions |
| 📘 Module N | Lessons + project for that module (one at a time) |
| 📋 Commands | Remembering commands |
| ❓ Quiz | Quick questions on weak spots |
| 🔁 Revise | Reviewing old topics |
| 🐞 Debug | Bug hunts |
| 📊 Progress | Big picture |
| 💬 Side chat | Any questions |
| 🎤 Mock interview | Interview practice |

## Golden rules
1. `sync` at the start and end of every session, on every PC.
2. Write all the code myself. Claude gives hints.
3. Stuck for 15+ minutes? Type `stuck`.
4. A module only counts when the project is on GitHub, live, and I can explain it.
