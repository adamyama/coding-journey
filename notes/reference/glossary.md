# My Coding Glossary

Every new coding word, explained simply. Claude adds words automatically as I learn them.
Type `glossary <word>` to look one up.

Words known: 10

| Word | Simple meaning | Tiny example | Module |
|---|---|---|---|
| Clone | Download a whole repo from GitHub to a computer for the first time | Clone `coding-journey` onto my other PC | Setup |
| Command | An instruction you type into the terminal | `git --version` | Setup |
| Commit | One saved version of your files, with a short note | "Add progress tracker" | Setup |
| Config | Settings for a program | `git config --global user.name "Adam Yama"` | Setup |
| Git | A program that saves versions of your code | Like "Save as v1, v2", but automatic | Setup |
| GitHub | A website that stores your Git repos online | Like OneDrive, but for code | Setup |
| Pull | Download the latest changes from GitHub | Get today's work on the other PC | Setup |
| Push | Upload your commits to GitHub | Send today's work online | Setup |
| Repo (repository) | A project folder that Git tracks | `coding-journey` | Setup |
| Terminal | A text window where you type commands instead of clicking | Command Prompt, PowerShell | Setup |
